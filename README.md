# Улаанбаатар хотын замын граф дээр маршрут тооцоолох бие даалтын ажил

**Алгоритмын бие даалт — BFS, DFS, Dijkstra**

## Товч тайлбар

Энэ төсөл нь Улаанбаатар хотын OpenStreetMap өгөгдөл дээр суурилж **графын хайлтын алгоритмууд (BFS, DFS, Dijkstra)**-ийг бодитоор хэрэгжүүлэн **хоёр цэгийн хооронд маршрутыг тооцоолох** веб систем бүтээсэн.

Бид багаар ажиллан:

* Графын онолын ойлголтыг судалж
* Алгоритмуудыг Python ба Java-гаар хэрэгжүүлж
* Frontend + Backend архитектураар веб систем бүтээж
* Алгоритмуудын үр дүн, ялгааг бодит өгөгдлөөр баталгаажуулсан.

## Багийн гишүүд

* Ц.Төгөлдөр
* Г.Нармандах
* Э.Амарболд
* Б.Тэмүүлэн

## Төслийн зорилго

* OSM shapefile өгөгдлөөс **замын граф үүсгэх**
* Хэрэглэгчийн сонгосон цэгүүдийн хооронд **маршрут тооцох**
* BFS, DFS, Dijkstra алгоритмуудыг **хооронд нь харьцуулах**
* Алгоритмуудыг **веб орчинд харагдахуйц, интерактив** байдлаар үзүүлэх

## Ашигласан алгоритмууд

### **BFS — Breadth-First Search**

* Жингүй граф дээр **хамгийн цөөн алхамтай зам** олно
* Төвшин дарааллаар хайдаг

### **DFS — Depth-First Search**

* Гүн чиглэлд хайлт хийнэ
* Замын урт оновчлохгүй ч графын бүтцийг судлахад тохиромжтой

### **Dijkstra — Weighted Shortest Path**

* Жинтэй граф дээр **хамгийн бага нийт зардалтай зам** олно
* Navigation төрөлд хамгийн бодитой

## Системийн бүтэц

### **Backend — Python + Flask**

* OSM shapefile → граф үүсгэх
* BFS, DFS, Dijkstra ашиглан зам тооцоолох
* JSON хэлбэрээр үр дүн буцаах

### **Frontend — HTML + JS + Leaflet.js**

* Улаанбаатарын газрын зураг үзүүлэх
* Эхлэх/төгсгөлийн цэг сонгох
* Алгоритм сонгоод маршрут харах

## Тест ба баталгаажуулалт

Бид алгоритмуудыг:

* Инвариант дээр суурилсан логик тестүүд
* Python/Java гүйцэтгэлийн харьцуулалт
* Frontend–backend интеграцын тестүүдээр
  баталгаажуулсан.

Үр дүнд:

* **BFS** → алхмын тоогоор хамгийн богино зам
* **DFS** → хүрч болох эсэхийг зөв илрүүлсэн
* **Dijkstra** → жингийн хувьд хамгийн оновчтой зам
  гэж батлагдсан.

## Бидний сурсан зүйл

Энэхүү төсөл нь бидэнд дараах чадварыг хөгжүүлэхэд туслав:

* Графын өгөгдлийг бодит газрын зургийн мэдээллээс үүсгэх
* BFS, DFS, Dijkstra алгоритмуудын практик ялгааг ойлгох
* Backend–Frontend хооронд REST API зохион байгуулах
* Алгоритмыг бодит асуудалд хэрэгжүүлэх

## Дүгнэлт

Бид багаараа бие даалтын ажлаа амжилттай хэрэгжүүлж:

* Графын алгоритмуудыг практикт туршиж
* Оновчтой маршрутыг интерактив хэлбэрээр харуулж
* Алгоритмын онолын мэдлэгээ программчлалд уялдуулж чадсан.

Энэ бие даалт нь графын алгоритмын **онол + практик** хосолсон сайн жишээ болсон.
